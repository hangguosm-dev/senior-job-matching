5W1H Framework Project

시니어 맞춤 일자리 매칭 서비스

건강 상태, 과거 경력, 근무 가능 시간, 현재 위치를 기반으로 65세 이상 시니어에게 적합한 일자리를 추천하는 웹서비스입니다.

서비스 개요

본 프로젝트는 초고령 사회 진입에 따라 노년층의 생산적 복지와 활동적 노화를 지원하기 위한 시니어 맞춤형 일자리 큐레이션 서비스입니다.

사용자는 앱 설치 없이 웹 브라우저에서 간단한 프로필을 입력하고, 건강 상태와 위치 조건에 맞는 일자리를 추천받을 수 있습니다.

5W1H 서비스 기획

Why

초고령 사회 진입에 따른 생산적 복지와 활동적 노화를 지원합니다.

Who

구직 의지가 있는 65세 이상 시니어와 노인 적합형 일자리를 제공하는 기관입니다.

What

건강 상태, 경력, 위치 데이터를 기반으로 일자리를 추천하는 웹서비스입니다.

When

은퇴 후 제2의 커리어를 찾거나 단기 일자리를 탐색할 때 사용합니다.

Where

모바일 웹 브라우저에서 사용하며 PWA 형태로 확장 가능합니다.

How

반응형 웹, 공공데이터 API, 카카오맵 API, 접근성 중심 UI를 활용합니다.

시니어 맞춤형 프로필

맞춤형 일자리 추천

거리, 건강 상태, 직무 조건을 기준으로 시니어에게 적합한 일자리를 추천합니다.

지원 현황 및 알림 시스템

지원 상태 변경 시 카카오 알림톡 또는 웹 알림으로 진행 상황을 안내하는 구조입니다.

구현 전략

  1. React 또는 Vue.js 기반 반응형 웹 구조 설계
  2. 공공데이터포털 노인일자리 API 연동
  3. 카카오맵 API를 활용한 거리 계산
  4. WCAG 기준을 고려한 고대비 UI 및 48px 이상 버튼 적용
  5. 지원하기 버튼, 예외 처리, 모달 테스트
